# 샌드위치 매매 (SOXL 계산표)

앱: https://hansangho1996-maker.github.io/sw_sh/

## 매수표 공식
- 엔진 e 시작가 = E1 × (1 − 엔진 하락폭)^e
- 세트 i 매수가 = 엔진 시작가 × (1 − 엔진 하락폭 × i / 엔진당 세트 수)
- 자동 세트금액: 전략자금 ÷ 총 세트 수
- 익절률: ATR% × 1.25, 최소 5% · 최대 10%

## 설정
- **엔진당 하락폭**: 기본 40%. 각 엔진이 시작가에서 몇 % 내려가 끝나는지.
- **계좌당 세트 수**: 기본 3. 매수표에 세트별 계좌 번호를 표시.

## 연말 절세 탭
올해 실현이익(원)에서 기본공제를 뺀 금액에 여유분을 더한 만큼, 평가손실이 큰 계좌부터 골라 보여줍니다.
- 고른 계좌는 전량 매도 후 같은 날 같은 계좌에서 같은 수량을 재매수합니다.
- 매수표·익절가·E1은 바꾸지 않습니다(세금 장부만 바뀜).
- 마감일은 국내 결제일이 12월 31일이 되는 마지막 미국 매매일입니다. 미국 휴장일은 반영하지 않으니 증권사 공지로 확인하세요.
- 평가손익은 매수표 가격과 입력한 환율로 계산한 추정치입니다. 실행 전 증권사 양도세 시뮬레이터로 확인하세요.
